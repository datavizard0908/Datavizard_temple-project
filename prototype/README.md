# 互動網頁原型（設計組）

`index.html` 是「神明住在哪裡？」互動網頁的設計原型，用來跟資料組對接。所有廟宇點位、年份與比較數字都是**示範用假資料**，正式版會換成 `data/processed/` 的真實資料。

## 怎麼看

直接用瀏覽器開 `prototype/index.html` 即可（需要網路，3D 與字型從 CDN 載入）。或：

```bash
python -m http.server 8765 --directory prototype
```

然後開 http://localhost:8765 。網址加上 `?lang=en` 會直接以英文開啟。

## 內容

整頁是一個隨捲動移動鏡頭的 3D 場景（three.js），右上角可切換中文／英文，右側圓點是章節導覽。

| 段落 | 內容 |
| --- | --- |
| 開場 | 夜空、月亮與燈籠，台灣的廟宇是一盞盞燈 |
| 第一章：神明的故鄉 | 海峽、祖廟光柱、遷移光弧與渡海帆船 |
| 第二章：城市與時間 | 台北盆地的城市量體與小廟、1853 頂下郊拚路線、時間軸 |
| 第三章：你家附近 | 選行政區，看方圓 1.5 公里內的廟 |
| 第四章：意外的比較 | 土地公比例、北中南東 3D 柱、廟與便利商店 |
| 第五章：自由探索 | 可拖曳、旋轉、縮放的 3D 地圖，含篩選、搜尋與時間軸 |
| 3D 大廟 | 8 間代表性大廟的風格化 3D 模型、建築細節導覽與廟宇檔案 |

## 目前是示意、正式版要替換的部分

- 廟宇點位與年份：改讀 `data/processed/temples_clean.csv`（或 `site/data/temples.geojson`）
- 海岸線與地形：目前是手繪示意，改用國土測繪中心界線與 DEM
- 台北建物：目前是程式生成的方塊，改用真實建物資料（內政部 3D 建物或 OpenStreetMap）
- 大廟模型：台北市的 5 間可換成 `data/reference/taipei_religious_3d_models_108.csv` 裡的真實模型（.kmz）
- 大廟的年份與沿革整理自公開資料，請資料組再核對一次
